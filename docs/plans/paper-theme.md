# 论文主题（Paper）接入用量看板

## 目的

在现有配色（默认 / Nord / Catppuccin / 抹茶）之外，加一套**学术论文图走进浏览器**的可选主题，用来对照 SaaS 仪表盘风。不改数据口径，不重写信息架构。

## 约束（第一性）

- 白底、正文 ≥17px、低饱和；无渐变 / 阴影 / 玻璃 / 彩虹 / 霓虹暗色。
- 分区：白卡片、细中灰描边、约 8px 圆角、极淡暖/冷色带。
- 定量图对齐 `scripts/analysis/plot_style.py`：去顶右边框、仅 y 向灰点线 `#808080`、柱为空心描边 + hatch、单图 ≤5 色、红仅告警。
- 论文主题固定亮色；暗色开关在该主题下禁用。

## 做法

1. `ThemePalette` 增加 `paper`，选择时强制 `mode=light`。
2. `index.css` 增加论文 token 与排版/chrome 覆盖（去玻璃、去阴影、放大字号）。
3. `chartChrome` 按 palette 切换网格与 hatch；柱状图、面积图接入。
4. KPI / 顶栏去掉彩虹色与玻璃；论文主题下标题用人话。

## 验收

切换到「论文」后：白底可读、柱有 hatch、网格只有横向点线、无阴影渐变；切回其他主题外观不变。

## 第二步：一屏一条论断

论文主题下（其他配色不动）：

1. 顶栏只留标题 + 一条主 CTA（同步）+「更多」里放身份 / 合并 / 重载 / 配色。
2. Tab 用人话短名（概览 / 周期 / 报销 / 模型）。
3. 概览：题头一条论断 + 对照行；宽屏（≥900px）两图并排，论断压紧贴在图上。不再用窄栏单列把图往下堆。
4. 去掉洞察 Banner 和五张 KPI 卡墙；缓存/池/模型结论收进题头一行，图本身带短论断。
5. 周期 Tab 同样：题头论断、两图并排、密表；不再通栏稀柱，也不再重复铺周期卡片。
